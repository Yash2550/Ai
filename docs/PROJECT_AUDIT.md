## 3. Critical Gaps Identified for Redesign & Integration

1. **UI Design Reference Alignment (`media_1795578932022_eaf38a97.jpg`):**
   - Replace current layout with the 6-region workspace: Dark Forest `#25372A` main sidebar, crisp white Top Editor Toolbar, compact Vertical Tool Rail (`AI Tools`, `Import`, `Text`, `Images`, `Shapes`, `Brand Kit`, `Layers`, `Nutrition`, `Background`, `Uploads`, `History`), AI Design Assistant drawer, Central Fabric.js workspace with pixel rulers + bottom Artboard status bar, and Right 3D Packaging Preview panel with 5 rendered packaging category thumbnails (`Protein Jar`, `Pouch`, `Sachet`, `Bottle`, `Box`) + 4 visual lighting cards.
   - Replace emoji UI icons with crisp Lucide SVG icons and use Inter / Plus Jakarta Sans typography.
2. **Eliminate Fabricated Numbers & Fake Statuses:**
   - Fix `/api/dashboard/stats` in `app.py` to return strictly real DB counts (`SavedProject`, `JobHistory`, `UploadedImage`, `ApiUsageLog`) with zero hardcoded minimums or invented costs.
   - Remove fake topbar wallet (`₹ 0` / `+ Add money`) and display real Save Status (`Saved`, `Unsaved changes`, `Saving...`) tied to persistence.
3. **3D GLB Loading & Physical Realism:**
   - Upgrade `scripts/generate_packaging_models.py` to generate smooth high-segment jar lathes, ribbed beveled caps, 24-vertex 6-face UV carton boxes, crimped heat-sealed pouches/sachets, and additional Protein Jar capacities (`100g`, `250g`, `300g`, `500g`, `1kg`, `2kg`, `2.5kg`, `3kg`, `5kg`).
   - Load `.glb` assets via `THREE.GLTFLoader` with `MeshPhysicalMaterial`, `PMREMGenerator` studio environment maps, crisp ground contact shadows, and `CanvasTexture` `flipY=false` calibration verified in real Chromium.
   - Render real PNG thumbnails for all 5 packaging categories using Playwright + Three.js.
4. **AI Assistant Modes & Non-Destructive Workflow:**
   - Expose all 6 AI Assistant modes (`Generate`, `Edit`, `Remove`, `Add`, `Replace`, `Perfect Text`) + Quick Tools (`Grab Text`, `Grab Object`, `Grab Logo`, `Background Repair`, `Smart Resize`).
   - Add non-destructive Before/After comparison modal before applying destructive AI edits.
   - Strictly forward selected `provider_id`, `model_id`, `aspect_ratio`, `quality`, `output_count`, and `reference_images` without silent provider switching.
